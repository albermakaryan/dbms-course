Four checks for any join

1

Did the inner join drop anything?

count rows with and without the join

2

Is a right-table condition in WHERE?

move it to ON

3

Does count(*) include empty matches?

count the right table’s key

4

One row per what, after the join?

don’t sum a “one”-side column over “many”-side rows
