-- 01 · data models · 1969

Network: records linked by pointers

Many parents allowed: one AirPods record, no copying.

But every question is a program: start at Davit, follow this pointer, loop over those.

Change the pointers and the programs break.

Sources: Wikipedia, “CODASYL” (network-model spec, 1969); C. W. Bachman, “The Programmer as Navigator”, CACM 16(11), 1973

CODASYL's Data Base Task Group published the network-model spec in October 1969, based on Charles Bachman's Integrated Data Store, which linked records with chains of pointers (Wikipedia, CODASYL). Bachman's 1973 Turing Award lecture was titled 'The Programmer as Navigator' (CACM 16(11)).
