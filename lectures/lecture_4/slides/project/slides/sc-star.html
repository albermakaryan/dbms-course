Shape 3: the star schema

fact: one row per order, the numbers you add up, plus a key to each dimension.

dimensions: the labels you group and filter by, one hop away.

grain: one row per order, written down before anything else.

Sources: Kimball Group, Dimensional Modeling Techniques: “Star Schemas”, “Grain”; Wikipedia, “Star schema”

Kimball Group: dimensional models divide data into measurements and the 'who, what, where, when, why, and how' context; implemented relationally as star schemas. 'The grain establishes exactly what a single fact table row represents.' Wikipedia, Star schema: fact tables hold numeric values and foreign keys; dimensions are denormalized. We build this in Part 6.
