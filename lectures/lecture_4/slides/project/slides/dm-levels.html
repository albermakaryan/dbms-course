Same shop, three levels. Conceptual: the owner's sketch. Logical: the architect's plan. Physical: the builder's drawing with the pipe sizes. Demo: \d orders. At the bottom, Indexes: "orders_pkey" PRIMARY KEY, btree (orderid). PostgreSQL creates a unique btree index for every primary key (docs: CREATE TABLE). Remove it and every query returns the same rows, only slower. That's what makes it physical.
