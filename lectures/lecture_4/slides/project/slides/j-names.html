Sources: PostgreSQL 16 docs, “Joined Tables” (USING, NATURAL); the error text is from running the Part 3 query

Error on purpose: SELECT orderID, customerID, firstName FROM orders JOIN customers ON customers.customerID = orders.customerID; The values are equal on every joined row, but the rule is about names, not values. Second error on purpose: SELECT orders.orderID FROM orders o ...; once a table has an alias, the alias is its only name. HINT: Perhaps you meant to reference the table alias "o".
